最終更新日: 2025-10-28

本プライバシーポリシー（以下「本ポリシー」）は、のりごろ（Norigoro Bus Timer）（以下「本アプリ」）におけるユーザー情報の取り扱い方針を定めるものです。

本アプリをご利用になる前に、本ポリシーをお読みください。

言語切替: 日本語 | [English](/apps/norigoro/privacy/en/)

注記: 日本語版と英語版に相違がある場合は、日本語版を正とします。

## 1. 収集する情報

本アプリは、バス到着時刻表示サービスを提供するため、以下の情報を取得します。

### 位置情報
- **目的**: 最寄りのバス停を自動検出するため
- **取得方法**: iOS Core Location API
- **保存**: 端末内のみ（最後に取得した位置情報を10分間キャッシュ）
- **外部送信**: なし（位置情報は一切外部に送信されません）

### デバイス関連情報
- 言語設定（システム設定から取得）
- システム時刻（到着時刻計算のため）

本アプリは以下の情報を**収集しません**：
- 個人を特定できる情報
- 連絡先、写真、カメラ、マイク
- 広告ID、トラッキングID
- 移動履歴、行動履歴

## 2. 収集方法

- ユーザーが位置情報の利用を許可した場合、iOS Core Location APIを通じて取得
- 端末のシステム機能（時刻、言語）からの情報取得

## 3. 利用目的

取得した情報は、以下の目的でのみ利用します。

- 最寄りのバス停の検索・表示
- バス到着時刻の計算・表示

## 4. データの保存・共有

### 端末内に保存されるデータ

すべてのデータは端末内のみに保存され、外部のサーバーには一切送信されません。

- **位置情報キャッシュ**: 最後に取得した緯度・経度（10分間のみ保存）
- **GTFSデータ**: バス路線・停留所・時刻表データ（公共交通オープンデータセンターから取得）
- **ユーザー設定**: 表示範囲、時間範囲、参考モード設定、最終更新日時
- **言語設定**: アプリ内の表示言語（システム設定から取得）

### 外部への送信

本アプリは、バス時刻表データとリアルタイム運行情報を取得するため、以下のAPIにアクセスします。

#### 公共交通オープンデータセンター（ODPT）API

- **送信情報**: なし（位置情報は送信されません）
- **取得情報**:
  - GTFSデータ（バス路線、停留所、時刻表）
  - GTFS-Realtimeデータ（リアルタイム遅延情報）
- **データソース**: 川崎鶴見臨港バス株式会社のオープンデータ
- **ライセンス**: 公共交通オープンデータ基本利用規約
- **データ情報**: https://developer.odpt.org/

位置情報から最寄りのバス停を検索する処理は、すべて端末内で完結します。位置情報がサーバーに送信されることは一切ありません。

### 第三者提供

以下の場合を除き、個人情報を第三者に提供しません。

- 法令に基づく開示要請がある場合
- 人の生命、身体または財産の保護のために必要で、本人の同意を得ることが困難な場合

本アプリは、広告配信、トラッキング、アクセス解析などのサードパーティSDKを一切使用していません。

## 5. データの削除

本アプリをアンインストールすることで、端末内に保存されたすべてのデータが削除されます。

アプリ内からデータを削除する方法：
- **位置情報キャッシュ**: 10分経過後に自動削除、または参考モードに切り替え
- **GTFSデータ**: アプリをアンインストール
- **ユーザー設定**: アプリをアンインストール

## 6. 位置情報の利用について

### 利用目的
位置情報は、最寄りのバス停を自動検出するためにのみ使用されます。

### 取得タイミング
- アプリ起動時（位置情報利用を許可した場合）
- 画面を下にスワイプして更新したとき
- 参考モードから通常モードに戻ったとき

### 保存期間
最後に取得した位置情報は10分間のみキャッシュされます。10分経過後、または参考モードに切り替えた場合は削除されます。

### 利用を停止する方法
1. iOSの「設定」アプリを開く
2. 「プライバシーとセキュリティ」→「位置情報サービス」を選択
3. 「のりごろ」を選択
4. 「なし」を選択

位置情報の利用を停止しても、参考モードで主要駅の時刻表を確認できます。

## 7. セキュリティ

本アプリは、ユーザー情報を保護するため、以下の対策を実施しています。

- 位置情報は端末内のみで処理し、外部に送信しない
- HTTPS通信による暗号化
- 最小限の権限のみ要求（位置情報のみ）
